# Chi-Square Distribution Modeling

MATLAB practical work on modeling and analysis of random variables with the chi-square distribution.

## Contents

`NormalRandomVariable.m` — standard Gaussian random variable
`ChiSquareManual.m` — chi-square distribution by summing squared normal variables
`ChiSquareThreeSigma.m` — three-sigma rule verification
`ChiSquareBuiltIn.m` — chi-square distribution using `chi2rnd`
`ChiSquareDof10.m` — chi-square distribution with 10 degrees of freedom
`NoisySignalChiSquare.m` — chi-square model based on noisy harmonic signals
