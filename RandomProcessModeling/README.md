# Random Process Modeling

MATLAB practical work on modeling and analysis of random processes.

## Contents

`ExponentialProcess.m` — process Y(t) = cos(U·t) with exponentially distributed U
`UniformPhaseProcess.m` — process Y(t) = cos(ωt + X) with uniformly distributed random phase
`GaussianHarmonicProcess.m` — process Y(t) = U cos(at) + V sin(at)
`GaussianLinearProcess.m` — process Y(t) = a + Ut + Vt

## Analysis

The practical work includes:
modeling random variables;
constructing realizations of random processes;
calculating mathematical expectations;
calculating correlation functions;
analyzing stationarity and ergodicity.
